## 遇到的问题和解决
1. 问题：`git push` 被拒绝（remote contains work that you do not have locally）。  
   解决：执行 `git pull --rebase origin develop`，处理冲突后再推送。  

2. 问题：CI 报错 `unable to find version`（Trivy action tag 无效）。  
   解决：将 action 引用改为有效版本/可用引用（如 `@master` 或有效 `v*` tag）。  

3. 问题：Docker 构建报错 `style.css not found`。  
   解决：调整 Dockerfile 的复制策略（避免硬编码复制不存在文件，改为按目录复制并通过 `.dockerignore` 控制上下文）。
